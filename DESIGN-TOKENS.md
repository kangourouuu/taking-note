# Context

As a developer, I want to design the project with taking notes easily and filtering them by project and tags.

## Frontend stack

- React with Vite and Tailwind CSS

## Dashboard

- Header will display the current month and user's functionalities dropdown at right corner (display as username)
- Below the user name will display the current project and tags and month dropdown
- The dashboard displays a monthly calendar view.
- Each day in the calendar can have multiple notes.
- Notes appear as chips on the calendar grid.
- Users can navigate between months by choosing filtering.
- The calendar will display with correct real-time date and order with Monday as the first

## Calendar Features

- Create, edit, delete, and view notes.
- Notes display a title or summary as a chip on the calendar.
- Clicking a chip opens the full note for editing or viewing.
- Filtering options: project and tags.

## Projects and Tags

- Projects are user-specific.
- Tags are user-specific.
- Projects and tags persist across sessions.
- Tags can be assigned to notes.
- Users can filter notes by project and tag.
- Filters apply to the calendar view.

## Color palette

- Project follows minimalist style so the main color will be white and black
- The tags will have the color picker as hex colors and choosing the tone for it
- Project will use Be Vietnamese Pro as main font
